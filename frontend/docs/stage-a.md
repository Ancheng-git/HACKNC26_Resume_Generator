# MineStory · 阶段 A 场景验证

日期：2026-10-10。分支：`codex/minestory-stage-a`。

## 本轮完成

- 原生 Three.js 场景，固定斜上方正交镜头；真实方块岛岸、草地、树冠、树干、花、小池塘和石板小径。
- 原创方块人物坐在树下休息，闭眼、弯膝、头部微倾；仅呼吸微动画，无起身或行走。
- 木结构玻璃生态小屋：透光和折射玻璃、环境反射、屋顶太阳能板、室内桌椅、绿植与灯具。太阳能板仅为环境模型。
- 明亮蓝色水面、柔和日照阴影、方块云、漂浮玻璃泡泡；微幅叶片、水面和云动画。
- 一条渲染循环，限制 DPR 为 1.5；页面隐藏或切换到业务页面时停渲染，回到场景恢复。系统 reduced-motion 默认暂停，界面也可暂停/恢复。
- 默认 `/` 与 `#scene` 显示场景；`#profile` 和 `#workspace` 保留原上传与申请界面。切换不刷新页面、不清空现有资料包与草稿。无 WebGL 或模块加载失败时显示提示，HTML 功能入口仍可用。
- 浏览器回归发现原资料面板在 1200px 宽度会向上越界，调整其桌面定位使其在宝箱左侧打开。

本轮没有把 3D 模型变成业务按钮，没有人物移动、登录、进入室内转场或新增后端请求。原上传与申请流程及接口字段保持不变。未修改后端，未推送、合并或发布。

## 浏览器验证

在用户当前 Windows 电脑的 Codex 内置浏览器实测；不是手机真机测试。以下尺寸是浏览器报告的 CSS 视口。内置截图有缩放空白边缘，截图只裁掉页面之外的边缘，没有改画面内容。

| 视口 | 检查结果 |
| --- | --- |
| 1200 × 750 | 场景正常；上传面板左右及上下在视口内；五个补充槽存在；未上传时 Start crafting 禁用；Esc 关闭资料面板 |
| 1366 × 768 | 场景正常；人物、树、小屋、玻璃、太阳能板与岛岸可见；标题无遮挡；无横向溢出 |
| 390 × 843 | 场景完整；按钮和导航可见；无横向溢出；暂停/恢复动画正常 |

申请工作台首次仅一个 `default`；输入 Title/Description 后往返场景，草稿保留。浏览器未发送实际资料上传或生成请求。

桌面活动场景的两秒采样约 **60 FPS**，约 **1460–1461 draw calls**（包含玻璃传输渲染）。这是该电脑及浏览器的观察值，不承诺其他设备帧率。后续阶段 D 可合批草地/岛岸几何、优化透明材质。暂停动画已实测；系统 reduced-motion 的分支已实现，本轮未更改操作系统偏好来模拟。

浏览器未发现场景控制台错误。生产构建和 `node tests/workspace.test.mjs` 通过；测试覆盖原接口流程及新增场景切换时资料 ID、申请数量和草稿保持。
